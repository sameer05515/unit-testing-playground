# Electron REST API Client V2

## Run

```bash
npm install
npm start
```

## Features

- Multiple request tabs
- Request collections
- Request history
- Query parameters
- Custom headers
- JSON/Text body
- JSON formatting
- Bearer Token authentication
- Basic authentication
- Environment variables
- `{{baseUrl}}` substitution
- Save requests locally
- Import/export collection JSON
- Response body and headers
- HTTP status, duration and size
- Dark/light theme
- Ctrl+Enter to send
- Ctrl+S to save

## Environment example

```text
baseUrl = http://localhost:8080
```

Then use:

```text
{{baseUrl}}/api/users
```

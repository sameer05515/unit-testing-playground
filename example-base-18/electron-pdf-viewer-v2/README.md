# Electron PDF Viewer V2

## Run

```bash
npm install
npm start
```

## Features

- Open local PDF
- PDF.js rendering
- Page navigation
- Page number input
- Zoom in/out
- Fit width
- Page thumbnails
- Thumbnail sidebar
- PDF text search
- Next/previous search result
- Ctrl+F search
- Ctrl+O open
- Recent PDF list
- Dark/light theme
- Keyboard navigation

PDF.js is pinned to 4.10.38 for Electron/Chromium compatibility.

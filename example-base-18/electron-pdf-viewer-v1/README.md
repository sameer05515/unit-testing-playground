# Electron PDF Viewer V1

## Requirements

- Node.js 18+
- npm

## Run

```bash
npm install
npm start
```

## Features

- Open local PDF
- Render PDF using PDF.js
- Previous / Next page
- Jump to page
- Zoom in / out
- Fit page width
- Keyboard navigation
  - Left / Right: previous/next page
  - Home: first page
  - End: last page
  - + / -: zoom
  - Ctrl + O: open PDF

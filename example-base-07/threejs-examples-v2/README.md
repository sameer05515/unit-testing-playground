# Three.js V2 — Practical Examples Playground

V2 expands the basic playground into practical Three.js patterns.

## Examples

1. Rotating Cube
2. Sphere + Lighting
3. Orbit Controls
4. Texture
5. 3D Text
6. GLTF/GLB Model
7. Animation Mixer
8. Raycaster / Object Picking
9. Particles
10. Solar System
11. Shadows
12. Multiple Cameras
13. Drag Controls
14. HTML Labels
15. Responsive 3D UI
16. Custom Shader Material
17. Procedural Terrain
18. Post Processing
19. Instanced Mesh
20. 3D Dashboard

## Run

```bash
npm install
npm run dev
```

Open the Vite URL, normally:

```text
http://localhost:5173
```

## Build

```bash
npm run build
npm run preview
```

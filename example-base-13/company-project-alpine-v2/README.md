# Company Project Explorer V2

HTML + Alpine.js + Tailwind CSS + Marked.js frontend using `data/data.json`.

## V2
- List/detail master-detail layout
- Search and project status filter
- Company -> Project navigation
- Markdown rendering for descriptions and notes
- Copy Markdown button
- Responsive Tailwind UI

## Run

```bash
python -m http.server 5500
```

Open `http://localhost:5500`.

Or:

```bash
npx serve .
```

The app loads Tailwind, Alpine.js and Marked.js from CDN.
